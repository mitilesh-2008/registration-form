A simple and user-friendly desktop registration form built using Python and Tkinter. It demonstrates GUI design, input fields, buttons, validation, and basic event handling in Tkinter.
# Python Tkinter Registration Form

A simple **Registration Form GUI** developed using **Python Tkinter**. This project is designed for beginners who are learning Python GUI development and want to understand how Tkinter widgets and event handling work.

## 🚀 Features

* User registration form
* Name input field
* Email input field
* Password input field
* Gender selection
* Date of birth input
* Submit and Reset buttons
* Basic input validation
* User-friendly graphical interface

## 🛠️ Technologies Used

* **Python**
* **Tkinter**

## 🎯 Purpose

The main purpose of this project is to learn how to create desktop GUI applications using Tkinter and understand the use of different widgets such as:

* Label
* Entry
* Button
* RadioButton
* CheckButton
* Frame

## ▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the Python file:

```bash
python registration.py
```

5. The Tkinter registration window will open.

## 📚 Learning Outcomes

Through this project, you can learn:

* How to create a Tkinter window
* How to use Tkinter widgets
* How to collect user input
* How to handle button events
* How to perform basic form validation
* How to organize a simple Python GUI project
